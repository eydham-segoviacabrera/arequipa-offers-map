# 🏷️ Arequipa Promos

Plataforma web colaborativa de ofertas y precios locales en Arequipa y el mundo.

## 🚀 Demo

👉 [Ver en vivo](https://eydham-segoviacabrera.github.io/arequipa-offers-map/)

## ✨ Características

- 🗺️ Mapa global interactivo (Leaflet + OpenStreetMap)
- 🔐 Autenticación con email (Supabase Auth)
- 📝 Publicar ofertas con coordenadas geográficas
- 🚨 Sistema de denuncias (3 denuncias = oferta oculta)
- 🔍 Búsqueda en tiempo real
- 🏷️ Filtros por categoría
- 🌙 Modo claro/oscuro
- 📱 Diseño responsive (móvil, tablet, desktop)

## 🛠️ Tecnologías

- HTML5 + Tailwind CSS (CDN)
- JavaScript Vanilla
- Leaflet.js 1.9.4
- Supabase (Auth + PostgreSQL + RLS)
